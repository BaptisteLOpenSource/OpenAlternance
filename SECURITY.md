# Sécurité

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique. Utilisez le signalement privé de GitHub :
[Signaler une vulnérabilité](https://github.com/BaptisteLOpenSource/OpenAlternance/security/advisories/new).

Indiquez la version ou le commit concerné, le mode (SQLite local ou Postgres Vercel) et les étapes
pour reproduire. Réponse visée sous 7 jours.

## Versions maintenues

Seule la dernière version de la branche `main` reçoit des correctifs.
